# vani.cost-price

Giá vốn theo SKU — plugin tham chiếu EP v3 X4 ([extension-point-catalog](../../../docs/04-extension/extension-point-catalog.md)).

- Trang làm việc bảng giá: công cụ **Nhập giá vốn** (file có cột `SKU`, `Giá vốn`), cột **Giá vốn**.
- "Áp giá…": cách tính **Giá vốn + %**, cách làm tròn **Giá đẹp đuôi 9.000** (191.000 → 199.000).
- Cảnh báo **Dưới giá vốn** trên dòng và trong xem trước — chỉ nhắc, không chặn.
