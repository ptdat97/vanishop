## Thang trạng thái

| Trạng thái | Nghĩa |
|---|---|
| **Implemented** | Code đã có, có test pass, dùng được theo đúng tài liệu |
| **Partially Implemented** | Đã có code nhưng thiếu phần đã thiết kế (ghi rõ thiếu gì) |
| **Designed** | Có thiết kế chi tiết trong `docs/`, chưa có code |
| **Planned** | Mới có ý định hoặc phác thảo, chưa có thiết kế chi tiết |

## Tổng quan

Đã có code: nền tảng (slice 0), Catalog → Order → Payment → Fulfillment → Returns (slice 1–9b), plugin chứng minh kiến trúc (slice 10), Integration platform phần lõi (slice 11), một cửa hàng — brand là thuộc tính catalog ([ADR-028](../19-adr/ADR-028-single-store-brand-as-catalog.md), slice 12), microkernel với chính sách thương mại là plugin hệ thống ([ADR-029](../19-adr/ADR-029-commerce-microkernel.md), slice 12d), Customer, Notification; vận hành nhiều kho là plugin `vani.warehouse` ([ADR-042](../19-adr/ADR-042-inventory-warehouse-plugins.md)). Trạng thái từng phần ở bảng bên dưới; lịch sử theo slice ở [roadmap §2](../20-roadmap/roadmap.md) và git history.
