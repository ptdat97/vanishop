> **Mục tiêu hiện tại (2026-10-08): một cửa hàng, một người bán.** Roadmap Phase 9 (ERP connector) và Phase 10 (Marketplace / Creator / Affiliate) đóng băng ([roadmap](../20-roadmap/roadmap.md)).

>
> Test: **838 test pass** trên SQLite in-memory và MySQL 8 (2026-10-07: gồm Phase 1 chuyển kho, Phase 3 đối soát tồn, Phase 4 đối soát event, Phase 3 đối soát thanh toán đã thu), cộng **9 concurrency test** (group `concurrency`, MySQL) pass. Chạy local Windows còn 5 fail **sẵn có từ trước, không liên quan thay đổi** (4 arch test + `HelloWorldPluginTest`): so sánh path dùng `/` trong khi Windows dùng `\` (vd. `CallerPlugin::resolve()` bỏ nhầm frame tự nó, `MicrokernelTest` không skip được `Tests/`) — CI Linux không ảnh hưởng.
>
> **Phase 1 hardening — chuyển kho có vòng đời (2026-10-15, Core 0.3.19)**: Inventory có `stock_transfers` + `stock_transfer_lines`, vòng đời `pending → shipped → received`/`cancelled`. `pending` không đổi tồn; `shipped` ghi movement `transfer_out` (trừ `on_hand` kho đi — hàng đang đi đường không bán được); `received` ghi `transfer_in` (cộng kho đến, nhận thiếu được); huỷ sau `shipped` nhập lại kho đi. Chỉ chuyển giữa hai location do VaniShop quản lý tồn; Admin → Tồn kho → Chuyển kho (`inventory.transfer`); event `StockTransferCreated/Shipped/Received/Cancelled`. Test: `StockTransferTest`, `StockTransferAdminTest`, `tests/Feature/Invariants/StockTransferInvariantsTest` (chạy `vani:inventory:verify` sau mỗi bước).
>
> **Phase 3 hardening — bảng đối soát tồn kho (2026-10-15, Core 0.3.20)**: `inventory_reconciliations` + `inventory_reconciliation_lines` dùng chung cho (a) đối soát nội bộ — `vani:inventory:verify` giờ **lưu phiên + dòng** vào bảng (trước: chỉ output + log; dòng đã sửa `resolution = repaired`), và (b) nguồn ngoài — `vani:inventory:reconcile --source=<mã authority> --file|--json=<snapshot> [--dry-run]`: so `on_hand` của VaniShop với snapshot (location, sku/variant, on_hand, version); phân loại `external_mismatch`/`reserved_mismatch`/`reserved_off_ledger`/`on_hand_off_ledger`/`negative_on_hand`; **không tự sửa phía ngoài**, chỉ áp phía VaniShop khi `locations.stock_authority = source` (movement `sync`, bỏ qua snapshot cũ hơn `sync_version`), còn lại ghi chênh lệch để xử lý tay. Admin → Tồn kho → Đối soát (chỉ đọc). Test: `ReconciliationTest`, `tests/Feature/Invariants/ReconciliationInvariantsTest`.
