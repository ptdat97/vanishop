# Trạng thái triển khai

> Cập nhật lần cuối: **2026-10-13**, sau slice Notification + plugin SMS/ZNS. Tài liệu này phải được cập nhật trong mọi PR làm thay đổi trạng thái một capability.

## Thang trạng thái

| Trạng thái | Nghĩa |
|---|---|
| **Implemented** | Code đã có, có test pass, dùng được theo đúng tài liệu |
| **Partially Implemented** | Đã có code nhưng thiếu phần đã thiết kế (ghi rõ thiếu gì) |

## Tổng quan

> **Slice 0 (Foundation) đã có code**: khung module, Shared, Tenancy/Brand/Channel tối thiểu, Identity (RBAC theo phạm vi, audit, đăng nhập Admin), Extension (hook + plugin system + CLI), khung Admin Inertia, plugin mẫu, CI. Chưa có giỏ, checkout, đơn.
>
> **Slice 1–9b đã có code**: Catalog, Product, Variant & Price, Inventory (giữ hàng không oversell, đã kiểm chứng bằng concurrency test nhiều tiến trình trên MySQL), Cart, Checkout (khuyến mãi + voucher, VAT, phí giao cố định, đặt hàng idempotent), Payment (COD, chuyển khoản thủ công, khung cổng online + IPN, hết hạn thanh toán, hoàn tiền), quản lý đơn (Admin, tra cứu/huỷ cho khách), giao hàng (vận đơn thủ công + khung hãng vận chuyển, webhook, trừ tồn khi xuất kho, thu COD, hoàn tất đơn) — luồng E2E COD chạy đầu-cuối qua API; đổi/trả (yêu cầu của khách, duyệt, nhận hàng, nhập kho, hoàn tiền).
>
>
> **Slice 10 (Proof plugins) đã có code**: ba plugin chứng minh kiến trúc thật sự cắm vào extension point của Commerce Core mà không vá Core — `vani.promotion-rules` (rule điều kiện khuyến mãi), `vani.vietqr` (cổng thanh toán QR động), `vani.ghn` (hãng vận chuyển + báo cước checkout). Mỗi plugin có contract test của Core, config riêng và bật/tắt theo scope `owner`/`brand`.
>
> **Slice 11 (Integration platform — phần lõi) đã có code**: module `Integration` với event feed + transactional outbox/inbox, worker nhiều tiến trình (`SKIP LOCKED`, giữ thứ tự theo đơn), retry/backoff/dead letter/replay, webhook ký HMAC cho đối tác, extension point `Connector`/`InboundHandler` cho plugin, Integration Client (key HMAC xoay vòng, scope, data scope brand, IP allowlist, rate limit), Integration API v1 (event feed, đơn hàng, xác nhận đơn, đồng bộ tồn từ authority ngoài), màn hình Admin "Tích hợp". Chưa có connector ERP cụ thể (chờ chốt ERP).
>
> **Slice Customer đã có code**: tài khoản khách hợp nhất theo SĐT cho mọi brand, đăng nhập OTP/mật khẩu (token Bearer, ADR-024), profile ẩn cho khách vãng lai (lịch sử đơn tự về tài khoản khi đăng ký), sổ địa chỉ, consent theo brand × kênh, merge, ẩn danh hoá, xuất dữ liệu, gộp giỏ khi đăng nhập, Admin khách hàng.
>
> **Slice Notification đã có code**: mẫu tin theo loại × kênh × brand, nhật ký gửi idempotent, gửi bất đồng bộ có retry, tin giao dịch đặt/huỷ đơn và giao hàng (email mặc định), consent cho tin marketing; plugin `vani.sms-brandname` (eSMS) và `vani.zalo-zns` là kênh gửi + kênh OTP (ZNS ưu tiên, tự dự phòng sang SMS).
>
> Test: **541 test pass** (unit, feature, architecture, contract) trên cả SQLite in-memory và MySQL, cộng **9 concurrency test** (group `concurrency`, chỉ MySQL).
